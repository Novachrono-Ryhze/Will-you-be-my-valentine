# My Personal Projects Collection

Welcome to my personal repository of projects!  
This repo contains projects I have built for fun, learning, and experimentation. It includes interactive web pages, animations, and other small coding experiments.

- **Other Web Projects**

  - Animated UI elements

  - Interactive buttons and overlays

- Responsive and interactive UI
- Simple animations and transitions
